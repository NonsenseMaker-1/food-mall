회사 홈페이지 틀 — 다른 노트북·계정으로 옮기는 방법
================================================

틀(메뉴, 디자인, 페이지, 관리자 화면)은 이 GitHub 저장소에 있습니다.
이 폴더만 복사하거나, 아래 주소에서 받으면 다른 PC에서도 같습니다.

  저장소: https://github.com/NonsenseMaker-1/food-mall
  공개 사이트: https://temporary-instant-poplar-2ji4sna.vercel.app
  관리자: https://temporary-instant-poplar-2ji4sna.vercel.app/admin.html

두 가지를 같이 씁니다. 어느 한쪽만 쓰지 않습니다.

  일상 관리: 관리자 페이지에서 공지·사진·가격·글을 고칩니다. Git/GitHub는 필요 없습니다.
  틀 보관: GitHub 파일이 원본입니다. 다른 노트북·계정으로 옮기거나 페이지 뼈대를 고칠 때 씁니다.

Vercel은 GitHub 원본을 인터넷에 보여 줍니다. 코드를 푸시하면 같은 주소가 갱신됩니다.


1. 다른 노트북 (같은 GitHub 계정)
--------------------------------
1) GitHub 사이트에서 로그인합니다. (비번은 여기 채팅에 치지 마세요.)
2) PowerShell에서:

   winget install --id Git.Git -e --source winget
   winget install --id GitHub.cli -e --source winget

   설치 후 창을 닫았다가 다시 연 다음:

   gh auth login
   git clone https://github.com/NonsenseMaker-1/food-mall.git

3) 받은 폴더에서 고친 뒤:

   git add .
   git commit -m "사이트 수정"
   git push origin main

   푸시되면 Vercel이 같은 공개 주소에 올립니다.

4) 로컬에서만 볼 때:

   python serve.py

   serve.py 와 admin-pass.txt 는 GitHub에 올리지 않습니다.
   새 PC에는 admin-pass.txt 를 직접 만들면 됩니다. (한 줄에 관리자 비밀번호)


2. 다른 GitHub 계정으로 소유권 이전
--------------------------------
저장소를 통째로 넘기면 틀이 그대로 갑니다.

1) https://github.com/NonsenseMaker-1/food-mall/settings/transfer
2) 받을 계정 또는 조직 이름을 넣습니다.
3) 받은 쪽에서 수락합니다.
4) Vercel → 해당 프로젝트 → Settings → Git 에서
   새 저장소 주소를 다시 연결합니다.

같이 쓰기만 하면 될 때는 Transfer 대신
Settings → Collaborators 에 상대 GitHub 아이디를 초대하면 됩니다.


3. 다른 Vercel 계정으로 호스팅만 옮기기
--------------------------------
1) 새 Vercel 계정으로 로그인합니다.
2) Add New → Project → Import Git Repository
   에서 NonsenseMaker-1/food-mall 을 고릅니다.
3) Deploy 하면 새 *.vercel.app 주소가 생깁니다.
4) 예전 주소는 이전 계정 대시보드에서 지울 수 있습니다.

이 PC 이름이 한글이라 Vercel CLI 로그인이 막힐 수 있습니다.
그때는 터미널이 아니라 https://vercel.com/dashboard 에서 하면 됩니다.


4. 절대 GitHub에 올리지 말 것
--------------------------------
  admin-pass.txt
  serve.py
  .vercel 폴더 (로그인 토큰이 들어 있을 수 있음)

admin.html 은 올립니다. 손님 메뉴에는 없습니다.


5. 일상 관리 (Git 없이)
--------------------------------
주소: https://temporary-instant-poplar-2ji4sna.vercel.app/admin.html

비밀번호를 치면 공지, 제품, 사진, 사이트 글을 고칠 수 있습니다.
이 방식은 유지합니다. GitHub에 올리지 않아도 관리자에서 저장할 수 있습니다.

참고: 관리자에서 올린 내용은 이 브라우저와 서버 메모리에 남습니다.
시간이 지나거나 사이트가 다시 올라가면 손님 화면이 예전 글로 돌아갈 수 있습니다.
그때는 관리자에서 다시 저장하면 됩니다.


6. 틀과 GitHub
--------------------------------
페이지 뼈대·자리표시([대괄호])·디자인은 GitHub에 있으므로
노트북을 바꿔도 틀은 유지됩니다. 이 방식도 유지합니다.


7. 사이트 이름 바꾸기 (Vercel 화면)
--------------------------------
https://vercel.com/dashboard → 이 프로젝트 → Settings → General
→ Project Name 을 원하는 영문 이름으로 바꿉니다.
공개 주소도 같이 바뀌면, 이 파일과 .github/workflows/health.yml
안의 URL을 새 주소로 고치면 됩니다.
